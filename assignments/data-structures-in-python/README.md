# 📘 Assignment: Data Structures in Python

## 🎯 Objective

Practice core Python data structures by building small, practical programs that use lists, dictionaries, sets, and tuples. By the end of this assignment, you will know when to choose each data structure and how to use them effectively.

## 📝 Tasks

### 🛠️ Build a Student Data Tracker

#### Description
Create a program that stores and updates student information using lists and dictionaries. Your program should maintain a list of student records where each record is a dictionary.

#### Requirements
Completed program should:

- Create a list of at least 3 students, where each student is represented by a dictionary with keys: `name`, `grade`, and `email`.
- Add a new student record to the list.
- Update one existing student grade.
- Print all student names and grades in a clear format.
- Allow searching for a student by name and print their full record if found.

### 🛠️ Analyze Collections with Sets and Tuples

#### Description
Write a second program section that uses sets and tuples to compare data and store fixed information.

#### Requirements
Completed program should:

- Create two sets of course topics and print the common topics between them.
- Print topics that appear in only one of the two sets.
- Create a tuple representing fixed classroom details in this format: `(room_number, teacher_name, max_students)`.
- Access and print each tuple value by index.
- Explain in a comment why a tuple is suitable for fixed classroom details.
